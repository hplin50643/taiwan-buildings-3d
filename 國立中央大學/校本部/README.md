### 既有批次來源與列印限制（數量為各批歷史範圍，非現行總數）


21件公開照片衍生的簡化外觀模型，含女十四舍主入口局部研究一件，以及工五B增建翼單獨模型。不是21棟完整測繪，也不代表全校完成。校本部位於桃園市中壢區；原20件含底座最長150 mm；新增聽松台街側模型長220 mm，皆為獨立比例近似。

## 驗證與證據界線

原有20件通過原始法線、邊與頂點流形、水密、單連通表面、正體積、乾淨重建同hash、Blender/STL一致檢查。0.2 mm有效截面補查共9097層通過；另行1 mm間距薄篩保留光電1層、遙測5層警示。需要支撐與實際切片評估，尚未正式切片或實體試印。

未知背面、深度與設備有明示簡化；照片拍攝年未提供時不以文件年替代。女十四舍不是整棟完整模型。模型原始參數可編輯，Blender是可編輯網格，不是BIM。來源原照片及內部並排圖不公開。

## 新增歷史原設計研究

陳其寛、劉應昌，T2另列黃寶瑜；CCCK19104006／007校核欄58.6.20（1969-06-20）原設計圖。槽內徑3.66／3.60m差異採T1不平均；槽內實心核、爬梯簡化及回彎管增粗為製造處理。精確現址與保存狀況未核，校本部僅作既有目錄分組，不宣稱已定位基地；非竣工或2026現況。

上述新增模型保留設計者與國立臺灣博物館典藏來源。來源圖像CC BY-NC標示（版本未明）與自行編寫程式／重建模型權利分開，不自動概括整包模型僅限非商業，也不宣稱已獲原圖或建築設計無限制商用權利。不附來源原圖、PDF或私人參考資料；皆未實體試印。
