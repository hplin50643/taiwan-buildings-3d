## 全國大專校院擴充進度

清冊分別記錄院校列冊、逐棟建築盤點、建模、驗證及發布狀態。**列入清冊不代表模型已完成；每校一件也不代表全校完成。** 已發布數以本頁圖鑑及[發布模型套件計數](../model-packages.json)為準。聯大及東海路思義教堂沿用既有檔案，不重複建模。
