# 公開交付文字隱私修訂

本副本僅處理公開證據文字中私人參考檔案的位置表示，改為「private-reference-not-included/檔名」。該標記不是下載連結，參考照片不包含於公開交付；原來源網址、照片內容雜湊與審核結論保持不變。

原交付包已獨立保留。本副本沒有改變模型幾何、逐面材質、色盤、場景或預覽圖。需要修訂的重建 ZIP 文字已同步，並以隔離解壓重建確認網格、材質與 3MF 和原交付一致。歷史審核及歷史校驗表仍保留其原版本含義；PRIVACY-REPAIR-SHA256SUMS 留存為隱私檢查階段的歷史快照；本次 README 重合併後的完整檔案校驗請使用 PUBLIC-MODEL-SHA256SUMS。

安全檢查程式中的禁止路徑類別字串是掃描規則，不是實際私人檔案位置，維持原樣，避免削弱檢查。公開說明不包含私人對照表。

本包稽核命中均為上述安全掃描規則，未發現需移除的實際私人路徑；模型原內容與重建 ZIP 均未變更。
