# 音圖中心：三模組有界整體研究組裝

**這是供檢視、重建與數位驗證的有界數位研究組裝，不是完整竣工館、原建築構造或經實印驗證的模型。**

本版將先前分層研究整合為三個可拆的數位框體、六個各帶專用人工支架的展示件，以及一塊帶庭院貫孔的共享人工底板，共十個實體。工作比例為 1:800，世界座標每 1 公尺對應模型 1.25 公釐。完整原始參考、各版失敗及修正證據均另保留，未覆寫。

## 必須先讀的來源限制

- 本案參考為112年5月第三版核定基本設計圖冊；主圖印有2023.04.20 DRAFT / NOT FOR CONSTRUCTION。不能當作最新設計或竣工實測。
- **B翼屋蓋的剖切位置存在重大異文**：總屋頂圖 A4.03 符號在B翼內的比例約0.1373，該剖面自己的小索引約0.2535；各自±3像素保守區間仍不重疊。保留的有限曲片只是條件式位置假設，不認真實切面。沒有用新平板補滿整個B屋，也沒有補未知外端。
- 南側上帶採固定名義X參考平面，不認真實X(z)、曲率或牆厚。7/8F的TYPE2詳圖沒有被搬到屋頂。
- 原B左整條端部仍有未解接口。實體僅採明示縮限的研究中段，端部人工留空不等於真接縫。
- 所謂「保留前界」只指有限平面基線及名義樓層基準，不代表整個5m或6.5m不透明牆面有來源證明。厚度、透明度、全層高、支架、連接軌、底板及裝配縫都是設計代理。
- 圖面不明的入口、階梯、門窗、服務中斷、天井空域及未解外端，不藉本版宣稱已補成真建築。

## 十件內容與檢視模式

A、B、CENTRAL三框各自連成一個數位實體；人工低位連接軌藏於共享底板凹槽，不是原建築樓板。六個可拆件為A兩片有限屋面、B有限假設屋面、南側名義帶、8F中央平台及5F L形平台。移除任何展示件時，連其專用柱、臂、帽一併移除。

- `assembled`：原組裝座標，無額外平移或旋轉。
- `hypotheses_removed`：關閉全部六個假設展示件及其專用支架，僅保留三框及人工底板。
- `source_only`：只顯示116個有限參考基線，不顯示全高不透明代理、人工底板支架或條件屋面。首層零高仍是人工展示基準，不是真地坪。
- `exploded`：分解展示用位移，**不是**實際裝配軌跡；精確位移及顯隱見 `VIEW-MODE-TRANSFORMS.json`。

所有灰色及分組色都只是示意，不代表原建築精確材色。

## 人工製造設計與差異

標稱背厚以0.8mm為起點；斜屋面向下的位移分別使用0.84/0.84/0.81mm，使候選主要面的法向間距約0.8046/0.8007/0.8071mm。這不是所有角點或全域最小壁厚證書。

- C8/L5名義平台保作底面，人工向上0.8mm，不能把製造頂面冒稱原finish標高。
- 七處模組角部轉交及人工切縫減少參考代理前域13.125mm²；B縮限製造端另減9.7609475mm²；A一個有限研究端再減0.9375mm²。原線都完整保留。
- C8、L5為可拆順序所需，製造投影已依B框掃掠及名義間隙作明列減域，不等原建築平台形狀。C8又裁除0.012441054867mm²的微薄人工末梢，原參考面不動。
- A0兩條人工橫臂及兩支柱頂下移0.05mm，消除背面點接；沒有平移屋面參考點。
- 十五處背部填角僅修人工框體的點／線接觸。曾撞廣域排除的A04填角沒有採用。
- A0、A1的局部共面薄折回，以精確相同有向外邊界重新三角化，沒有近點焊接或移動存留頂點；舊有自交版保留。

共享底板厚2mm，槽底−1.2mm，剩餘底厚0.8mm。柱腳延至槽底作名義止擋；槽與柱名義單側差0.15mm。這些是未實測的設計值，不是打印公差或抗倒、承重保證。

A0人工高支架占用未重建的室內／屋突位置，且鄰近階梯的圖面距離不足以證實真淨距；這是明示研究取捨，不宣稱該處原本沒有房間、設備或樓梯。

## 數位檢驗與仍未證事項

各實際STL須逐件驗有限頂點、非退化三角、反向雙邊、頂點link、連通、正體積及自交。曲件還須比較原始凸primitive聯集與實際表面，**不得把有向總體積接近稱為占域精確一致**。非零float32 Boolean差須逐項保留。

裝配檢查採實際三角面完整連續垂直掃掠，順序為：底板 → CENTRAL → A → B → C8 → L5 → A0 → A1 → B有限屋片 → 南帶；拆卸採相反順序。零正體積干涉不代表有足夠物理間隙。槽底及部分件間為名義零隙接觸。

方向chord篩查、主要面法向厚度、連通及數位掃掠都不等於全域最小頸厚、材料強度、列印支撐可行性或已實裝。未指定印表機、噴嘴、材料及工法，沒有G-code、支撐或實印保證。每件的模型座標是組裝座標，直接置床需另選列印方向，不能把整組一鍵切片當作已驗證方案。

## 重建與檔案

`parts/` 為毫米單位的分件STL；`assembly.3mf` 保留毫米、十個分件及原組裝座標（單位矩陣，無額外平移或旋轉）。`scene.blend` 用於研究檢視，不含原PDF或私人來源圖片。

最終檢驗、重建與manifest仍以隨包報告為準；本README不自行將尚待獨核項標成PASS。

### 兩種不同的重建入口

- `python rebuild_all.py /path/to/new-empty-directory`：從隨包的小型數值製造參數開始，重新執行正交格網聯集、四曲件Blender Boolean、精確局部重分割，產生十STL、3MF、場景及八張原圖／caption圖。沒有複製既有STL、scene或physical-meshes快照作生成輸入。需要Python3、NumPy、Pillow及Blender4.3.2；不連網。輸出目錄必須尚不存在。
- `blender -b --factory-startup --disable-autoexec --python build_scene.py`：只用已凍結的 `inputs/physical-meshes.json` 重建檢視場景與四張原始圖，屬呈現層，不能單獨當製造幾何重建證明。

完整空目錄重建已執行，十STL與3MF逐byte一致，幾何記錄一致，四張原圖及四張caption圖的全部RGBA像素一致。見 `qa/FULL-EMPTY-DIRECTORY-REBUILD-WITH-CAPTIONS.json`。這不包含從原PDF自動重新解讀／追線；來源語義與人工參數仍須審核，原參考PDF及私人衍生圖未隨包散布。

### 本版已完成的數位結果

十件合計95310三角；各件實際檔案為單一連通、閉合且一致定向的表面，沒有退化面。正交六件以完整座標格網占域生成，曲件四件另做所有三角對的精確有理數自交檢查。

四曲件對其**給定float32製造輸入**的完整有限前面，增面、漏面皆精確為零；這不追認來源建築真實表面。人工背／側面與支架的Boolean數值差仍存在：A0、A1、B的普通集合對稱差分別為0.00010714908425、0.00020341016818、0.00010183958680mm³，南帶為精確零。沒有把非零差改寫成「占域完全相等」。

逐有限邊界面片的Minkowski立方包絡，以精確有理數裁切證立四件全部表面雙向覆蓋：L∞距離上界5×10⁻⁶mm，故歐氏距離上界8.660254037844387×10⁻⁶mm。這包含孔和內凹，並非整件取一個凸包；各差域角色及保守位置包界見 `qa/curved-domain/FINAL-INDEPENDENT-CURVED-DOMAIN-V7.json`。位置包界不是最小增／漏料分區，也沒有把體積誤差按角色作未證分配。

全十件45對以實際下向／上向三角面核連續垂直插入，無正體積阻擋，並核STL與幾何JSON有向三角集合一致。來源／假設件移除及僅參考線模式已實際重開驗證。四種視圖皆以全可見頂點投影驗邊界；最小畫布邊距31.871像素，caption另加在原畫布外。

方向chord掃描沒有剩下原C8微薄尾。部分名義0.8mm的實際float32值最低約0.79998779mm，數值差如實保留；這不是用新的容差宣稱全域最小壁厚或實印合格。

可額外執行 `python verify_sweep.py /path/to/new-sweep-check`，以本包實際十STL／幾何重核全組連續垂直掃掠；`python verify_curved_exact.py /path/to/new-exact-check` 則由隨包製造輸入重核四曲件的精確嵌入、占域差、有限前面與完整邊界包絡。兩者都不下載原圖；精確曲件檢核另開新目錄，僅重綁輸入路徑，不改演算法。這些腳本不能代替實際列印及裝配測試。
