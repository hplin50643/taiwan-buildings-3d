# 泳健館｜原構件完整返面補色

## 範圍與原檔保留

國立臺北教育大學臺北校區泳健館，沿用原1779頂點、3774三角面與150×101×36.5mm。頂點、面繞序、transform、尺寸、原910個彩面與全部四種原材質的RGBA、Principled Base Color、roughness逐項不變。只變更64個原材料0三角面的材料指標。原STL、scene.blend、參數生成器、七張鎖定preview與原幾何QA未替換，無新增文字或幾何。本輪不把原製造檢查當成新的現場測試。

- [謝寶幸福窩入口實拍](https://hsiehbaby.blogspot.com/2012/05/blog-post_15.html)：本輪親看入口夜景IMAG1367及池內IMAG1366。入口圖有灰框連續內側及大頂板底面，支持同一灰構件延續；夜景有明顯藍光偏色，只判材料家族，不用夜間色調另造色票。頁面2012-05-16不是可驗證的每張拍攝日期。
- [iPlay場館資料](https://iplay.sports.gov.tw/gyminfo/index/2518)：本輪親看泳池及教室兩張圖。池內有磚柱／端牆、灰窗框與大量玻璃；教室白牆不能外推成外牆白色。
- [場館營運方照片](https://handlepower.net/space/service3.html)及[LEADER泳健館照片](https://www.leaderonline.com.tw/Venue/VenueView.php?no=5)：本輪親看池內不同角度。LEADER圖顯示兩條長側均有窗與磚柱，不能把原簡化模型僅兩面構成的整片背牆當成完整磚牆。
- [綠野國際建築師設計說明](https://www.gfa.tw/project/城市文化的發電機-北師美術館教學大樓與游泳池/)：文字明述泳池棟東西向綠牆，提示其外牆並非單一裸磚配置。照片連結本輪HTTP403，未重試／改路徑取得，不宣稱看過那些圖片。模型軸向不是測繪地理方向，無法將綠牆精確定位到原三角面。

來源照片、PDF、HTML只作私人查核，不納入公開模型包。共親看八張照片（官方兩張及另六張）與一頁平面。所有新資料僅支持歷史材料與構件延續，不構成2026外觀、營運或設備現況保證。顏色維持原視覺近似值，不是校準色票。

## 64面完整分類

先重現前版材料分類，再只對原材料0處理。所有三角形三個頂點必須同在一個原構件凸包及其原支持平面，依表面法線指定內／外側；不用三角中心點切色，也不新增面、貼圖或窗。

1. 32面：右端四組原窗洞的四邊完整返面沿用紅磚材料。洞口周圍磚牆有直接照片，內凹深度上的精確材質是同構造延續推估，不聲稱窄邊實測。原藍灰窗背不變，不新增窗框細節。
2. 16面：原灰入口兩道側牆的後端面沿用灰材料。既有前與側面已灰，後端只補該原實體內的完整平面；不染鄰接樓梯或後側欄杆。
3. 14面：原入口頂板的完整底面、頂面及後端沿用灰材料。底面可在官方及入口照片辨識，未入鏡頂面／後端列同構件推估，不把投影陰影當黑漆。
4. 2面：原連續花臺右端沿用前面灰材料；頂部與背部的實心槽體代理仍中性，避免把未建的植栽或土面灰染。

[逐面索引與理由](appearance-materials.json)和[面界審核](appearance-review-v2/boundary-continuity-audit.json)可查。每個變更面全頂點檢查外，另測28個重心座標取樣點，精確匹配相同構件家族。凸三角形／凸支持盒的全頂點包含即涵蓋全三角面。

## 為何其他面保留中性

舊版中性不是一律禁止推估。本版已補可辨識完整構件，但未將真正跨材料無界或人工簡化表面偽裝成實物。

- 原五道粗遮陽條對應紅棕與黑灰兩系統，沒有符合實物的細分材料界，故相關1380個原中性面不變。不把其中一個三角形染成上紅下黑，也不按面中心階梯式分色。
- 原大背牆只有兩個三角面（161、362），範圍x=-69至69、y=36、z=3至33.1mm。新讀池內對向圖顯示長側有大量窗，建築師另提綠牆；不能把該無窗代理整片塗磚色或玻璃色。
- 左端主牆完整外側面91、158、159、160沒有確定材料界／綠牆對映，保留中性。一般長正牆也不把灰結構／窗區混合區一律塗磚。
- 主屋頂、壓頂、入口地面與階梯、上方連接欄杆、入口其他背牆、花臺槽頂／背部、柱頭和剩餘交接片保留中性。人工底座不假作建築外牆。

仍有2800面中性；這不是說實物沒有顏色，也不是全館材質復原。沒有補造植物、窗、欄杆細件、玻璃反射物或設備。

## 重建與渲染驗證

Blender4.3.2，以原scene.blend、model.stl與本版build_appearance.py同目錄執行：

    blender -b -t 1 --python-exit-code 1 -P build_appearance.py

七張新版front／rear／elevation／source-angle／left／right／top均900×800，Cycles CPU、96samples、seed0、單執行緒、無降噪。兩張原版同相機對照沿用相同燈光、相機、材值，只還原面指標。相機數值精確一致。無文字物件、stamp與PNG文字metadata。

BLEND逐點逐面、transform、尺寸和材值比對原版；3MF逐點逐面連接與材質、單位、build項目、palette皆核對。乾淨目錄以原scene.blend及新腳本重建，3MF與材料JSON逐byte相同；BLEND以網格、材料、transform語義精確相同驗證，不要求容器byte相同。

原appearance-review保留為前版歷史，新版由appearance-review-v2、appearance-freeze.json及模型SHA256SUMS綁定。校級checksum未更改，必須在授權發布整合時重算。
