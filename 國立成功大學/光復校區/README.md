# 國立成功大學・光復校區

[返回學校總覽](../README.md)

本校區目前收錄 20 件數位外觀近似模型；包含局部段或同一財產不同量體，件數不等於完整建物棟數。原16件含底座最長150mm；波簷尖峰片段為104mm展示底座寬，小西門為108mm展示寬，懸鏈・榭歷史實作亭為約157mm展示寬，各件獨立縮尺；懸鏈・榭場址為成品與校方院照交叉定位推論，不表示目前仍存。尚未完成全校，未實體試印或進行印表機切片驗證。

## 光復操場司令台新增範圍與來源

1981原建築圖外觀近似，不是竣工測繪或2026現況；HP曲率與薄殼厚度為參數化／列印近似，不含地下構造、隱藏房間或鄰接看台。

設計者、典藏來源與原圖CC BY-NC標示保留，來源頁未明示版本；原圖像權利與自行編寫程式／重建模型分開說明，不因來源標示而一概將整包模型限制為非商業，也不宣稱已取得原建築設計或原圖的無限制商用權利。原照片、圖紙、PDF與私人參考資料不隨公開包配送；所有模型未實體試印。
